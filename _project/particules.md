# PARTICULES

**Particules** is a real‑time polyphonic granular synthesizer, developed in C++20 with the JUCE framework.

In order to meet real‑time audio requirements, the engine guarantees that the DSP runs without any blocking and without any dynamic allocation.

The architecture is designed to clearly separate the DSP from the user interface as well as the communication layers.

The plugin is also polyphonic with a maximum of 8 voices for musical granular synthesis.

# PARTICULES

**Particules** est un synthétiseur granulaire polyphonique temps réel, développé en C++20 avec le framework JUCE. 

Dans l'objectif de répondre aux exigences de l'audio en temps réel, le moteur garantit que le DSP fonctionne sans aucun blocage et sans aucune allocation dynamique. 

L'architecture est conçue de sorte à clairement séparer le DSP de l'interface utilisateur ainsi que les couches de communication. 

Le plugin est également polyphonique avec un maximum de 8 voix possible pour une synthèse granulaire musicale.
